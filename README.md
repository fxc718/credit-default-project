# 信贷违约风险预测项目
基于Kaggle Give Me Some Credit真实信贷数据集，构建信贷违约预测模型，识别用户发生严重逾期的概率。完整复现风控建模标准流程：探索性数据分析EDA → 数据清洗与异常处理 → WOE分箱+IV特征筛选 → 模型训练 → 模型评估（AUC、KS、PSI）→离线预测推理，完整模拟金融风控业务建模流程。

## 业务背景
金融机构需要提前识别信贷客户违约风险，对高风险客户进行额度管控、风险预警，降低坏账损失。
任务：二分类预测，标签`SeriousDlqin2yrs`，1代表未来两年发生严重违约，0代表正常履约。

## 数据集
来源：Kaggle Give Me Some Credit
样本：13万条信贷用户数据，10个原始特征，样本存在类别不平衡。
> 原始csv文件不上传仓库，运行前请手动创建本地 `data/` 文件夹，把 Kaggle 下载的数据集放入该目录。

## 项目目录结构
- `eda/`：探索性数据分析与建模脚本
  - `01_eda_analysis.py`：EDA探索性分析，标签分布、缺失值、异常值统计
  - `02_data_clean.py`：数据清洗，异常值剔除、缺失值填充
  - `03_woe_iv_feature.py`：WOE分箱、IV计算，完成特征筛选
  - `04_model_train.py`：逻辑回归、XGBoost模型训练，保存模型文件
  - `05_model_evaluate.py`：模型评估，计算AUC、KS、PSI特征稳定性、特征重要性
  - `06_predict.py`：新样本预测推理脚本
- `data/`：数据集存放目录（原始数据不上传git）
- `output/`：输出结果，指标csv、评估图表（本地运行生成，不上传git）
- `models/`：训练产出模型、分箱WOE映射文件（不上传git）
- `requirements.txt`：项目依赖包清单
- `.gitignore`：git忽略配置文件

## 建模流程
### EDA
1. 数据集共13万样本，标签`SeriousDlqin2yrs`存在严重类别不平衡，负样本（不违约）远多于违约样本。建模放弃准确率，选用AUC、KS作为核心评估指标。
2. 缺失情况：`MonthlyIncome`（月收入）缺失占比约20%；`NumberOfDependents`（家属数量）缺失约2.5%。信贷场景的缺失具备业务含义，不直接删除样本，新增缺失标记特征保留风险信号。
3. 逾期相关特征存在特殊编码96、98，并非真实逾期次数，属于数据异常，清洗阶段替换为0。
4. 存在年龄小于21岁的不合理样本，不符合信贷业务准入规则，后续进行过滤。
5. 特征相关性：不存在极强多重共线性，大部分特征可以保留进入分箱流程。

**EDA总结**：数据集存在样本不均衡、字段缺失、特殊异常编码、不合理样本等真实业务问题；整体特征区分能力尚可，经过清洗预处理，可开展后续特征工程与建模。

### 数据预处理
剔除年龄小于21岁不合理样本；逾期字段特殊编码96、98替换为0；针对高缺失字段新增缺失标记特征；对收入、负债等数值特征做异常值缩尾处理；剔除无区分能力常量字段；分层抽样划分训练集/测试集，规避数据泄露。

### 特征工程
若全部特征统一使用等频`qcut`分箱，大量样本取值为0的逾期计数特征会被合并为单一分箱，IV趋近于0，存在误删核心风险特征的隐患。

因此采用差异化分支处理策略：
- 普通连续特征：等频分箱；
- 少取值离散特征：直接原值分组；
- 逾期计数类特征：自定义业务分箱，保护核心逾期风险特征。

分箱后计算WOE表征区间风险倾向，通过IV筛选`IV>0.02`的有效特征，同时人工调整分箱保证违约率满足单调性。
> 将分箱边界、WOE映射字典持久化保存，推理阶段仅执行`transform`，禁止`fit`，防止线上数据泄露。

### 模型训练
分层抽样划分训练集/测试集，分别训练**逻辑回归基线模型**与**XGBoost模型**。
- 逻辑回归：可解释性强，适配金融风控评分卡业务场景；
- XGBoost：捕捉非线性特征交互与特征组合效应，用于效果对比。

针对样本不平衡设置类别权重，提升违约样本识别能力；训练完成持久化模型对象与入模特征列表，保障推理阶段特征顺序完全对齐。

### 模型评估
计算AUC、KS衡量模型风险区分能力；PSI检验训练/测试集特征分布稳定性；分析XGBoost特征重要性，挖掘违约关键因子。

#### 实测实验结果
|模型|测试集AUC|测试集KS|PSI|最优阈值|
|----|---|---|---|---|
|逻辑回归|0.8532|0.5630|0.0002|0.4580|
|XGBoost|0.8619|0.5739|0.0006|0.0627|

**结果解读**
1. 区分能力：两个模型均达到风控业务可用标准；XGBoost指标小幅高于逻辑回归，但提升幅度有限，说明特征工程已经充分挖掘风险信号。
2. 稳定性：两个模型PSI均远小于0.1警戒线，训练、测试样本分布一致性良好。
3. 阈值现象：XGBoost最优阈值偏低，输出违约概率整体偏小，存在概率校准问题，后续可采用`CalibratedClassifierCV`做校准优化。
4. 业务权衡：逻辑回归可解释性强，满足金融监管要求；XGBoost效果微增，但可解释成本高。

### 预测推理 & 风控业务策略（06_predict.py）
本脚本面向新样本做离线推理，严格遵循**训练‑推理分离原则**：加载本地保存的分箱边界、WOE映射、模型文件、特征列表，只执行transform，不重新拟合任何规则。

1. 同时输出`lr_prob`、`xgb_prob`预测违约概率(0~1)；
2. 使用各自实验得到的最优阈值生成违约标签：`1=预测违约（高风险），0=正常履约（低风险）`；
3. 推理结果输出至`output/predictions.csv`；
4. 业务上可根据坏账率、通过率目标动态调整决策阈值，边界风险样本可增加人工复核流程。

## 复现说明
1. 从 Kaggle 下载数据集，放置到 `data` 文件夹
2. 按顺序运行脚本：
`01_eda_analysis.py` → `02_data_clean.py` → `03_woe_iv_feature.py` → `04_model_train.py` → `05_model_evaluate.py` → `06_predict.py`
3. 运行完成后，输出结果会保存在 `output` 文件夹，模型、分箱映射文件保存在 `models` 文件夹。
