# 信贷违约风险预测项目（风控建模）
基于Kaggle Give Me Some Credit真实信贷数据集，构建信贷违约预测模型，识别用户发生严重逾期的概率。完整复现风控建模标准流程：探索性数据分析EDA → 数据清洗与异常处理 → WOE分箱+IV特征筛选 → 模型训练 → 模型评估（AUC、KS、PSI），模拟金融风控业务建模流程。

## 业务背景
金融机构需要提前识别信贷客户违约风险，对高风险客户进行额度管控、风险预警，降低坏账损失。
任务：二分类预测，标签`SeriousDlqin2yrs`，1代表未来两年发生严重违约，0代表正常履约。

## 数据集
来源：Kaggle Give Me Some Credit
样本：13万条信贷用户数据，10个特征，样本存在类别不平衡。
> 原始csv文件不上传仓库，下载后放置在`data/`文件夹下即可复现。

## 项目目录结构
- `eda/`：探索性数据分析与建模脚本
  - `01_eda_analysis.py`：EDA探索性分析，标签分布、缺失值、异常值统计
  - `02_data_clean.py`：数据清洗，异常值剔除、缺失值填充
  - `03_woe_iv_feature_selection.py`：WOE等频分箱、IV计算，完成特征筛选
  - `04_model_train.py`：逻辑回归、XGBoost模型训练，保存模型文件
  - `05_model_evaluate.py`：模型评估，计算AUC、KS、PSI特征稳定性、特征重要性
- `data/`：数据集存放目录（原始数据不上传git）
- `output/`：输出结果，包含指标csv、可视化图片（本地运行生成，不上传git）
- `requirements.txt`：项目依赖包清单
- `.gitignore`：git忽略配置文件

## 建模流程
1. EDA：统计标签分布、缺失值、异常值，查看各特征分布情况
2. 数据预处理：剔除不合理极端异常值，对缺失值做中位数/0填充
3. 特征工程：连续特征等频分箱，计算WOE与IV，筛选IV>0.02的有效入模特征
4. 模型训练：分层抽样划分训练集/测试集，分别训练逻辑回归基线模型与XGBoost模型
5. 模型评估：计算AUC、KS衡量区分能力；PSI检验训练/测试集特征分布稳定性；分析XGBoost特征重要性，挖掘违约关键因子

## 实验结果
- 逻辑回归：测试集AUC≈0.5，几乎不具备风险区分能力
- XGBoost：训练集AUC=0.871，测试集AUC=0.869，KS=0.582；训练与测试指标接近，无明显过拟合
- 全部入模特征PSI＜0.1，特征分布稳定，满足风控上线稳定性基本要求
- 特征重要性：**90天逾期次数**是预测违约最重要特征，其次为循环信贷使用率，结果符合信贷业务常识

## 复现说明
1. 从Kaggle下载数据集，放置到data文件夹
2. 按顺序运行脚本：
01_eda_analysis.py → 02_data_clean.py → 03_woe_iv_feature.py → 04_model_train.py → 05_model_evaluate.py
3. 运行完成后，输出结果会保存在output文件夹，模型保存在eda文件夹。
> 数据集、模型、可视化图片不会提交到Git仓库。
